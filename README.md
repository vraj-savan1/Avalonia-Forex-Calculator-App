# Forex Position Calculator

A basic prototype of a Forex position size calculator built using C# and Avalonia UI.

This project was created to explore desktop application development, UI design, and implementing financial calculations in C#. The current version focuses on the core functionality of calculating risk, position size, pip distances, and risk-to-reward ratios.

# Current Features

- Account balance input
- Account currency selection (USD, GBP, EUR)
- Risk percentage calculation
- Currency pair selection
- Entry price, stop loss, and take profit inputs
- Stop loss and reward pip calculations
- Risk-to-reward calculation
- Position size calculation (lot size)
- Modern dark-themed user interface built with Avalonia UI

# Prototype Status

This is currently a basic prototype and is not intended to be used for live trading decisions.

The current version uses simplified calculations and hardcoded pip values. It was developed as a foundation for future improvements and further experimentation.
